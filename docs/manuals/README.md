# Server manuals

These manuals explain how to set up and operate the server without needing to
read the C source or API reference.

## Choose a manual

- [Getting started](getting-started.md): build, launch locally, and open the
  web pages.
- [User printing guide](printing.md): sign in, select documents, set options,
  submit grouped jobs, and follow their status.
- [Administrator guide](administration.md): configure CUPS, manage accounts,
  reset passwords, block users, and adjust credits.
- [Operations and maintenance](operations.md): configure HTTPS and domains,
  check logs, back up the database, and troubleshoot service issues.

For exact configuration keys, API request formats, and implementation details,
see the [technical guides](../../README.md) linked from the repository README.
